# Chatbot Dashboard

Next.js 14 tenant dashboard for managing the chatbot SaaS.

## Development

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build

```bash
pnpm build
pnpm start
```

## Features

- Next.js 14 with App Router
- Tailwind CSS for styling
- TypeScript support
- Shared UI components from `@chatbot/ui`
