- The application always runs inside Docker
- Use Docker and docker-compose for all commands
- Never assume local host execution
- Databases and services run as containers
- Prefer container-friendly debugging steps

hot coding changes are already there for some of the folders so before building it is recommended to check if the changes are already there. If not, you can make the changes and then rebuild the container.

## CRITICAL: No Local Installs
- **NEVER run `pnpm install`, `npm install`, `pip install` or any package manager on the host machine**
- To add dependencies: edit `package.json` (or `requirements.txt`) and rebuild the Docker container with `docker-compose up --build <service>`
- Run commands inside containers: `docker-compose exec <service> <command>`
- Container names: `chatbot_web` (Next.js), `chatbot_api` (FastAPI), `chatbot_widget` (Preact widget)
- Dev compose file: `docker-compose.yml` | Prod: `docker-compose.prod.yml`
